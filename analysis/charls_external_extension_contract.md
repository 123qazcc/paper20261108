# CHARLS 疾病特异性外部拓展：分阶段分析约定

2026-09-13：CHARLS 分析是基于既有 HRS/ELSA 结果设计的外部拓展，不属于预注册验证。

## 范围与顺序

1. 本轮：来源核验、睡眠暴露重建、疾病编码与缺失核验、W1 基线表、可观察转移计数。
2. 下一阶段：原始疾病问卷路由及死亡资料覆盖审计；冻结最终分析人群、Q 矩阵、调整集及疾病特异插补辅助变量。
3. 此后：模型、诊断、四条目标转移及正式系数对比、完整敏感性结果和图件。
4. 睡眠时长—血压 RI-CLPM 是另一个后续模块，本轮不启动。

HRS/ELSA 已冻结结果不修改；原有三库清洗文件也不覆盖。新结果位于 `outputs/charls_external_extension_20260913/`。第一阶段不得输出 HR、转移强度或疾病特异性关联结论。

## 第一阶段测量与可重复实现

- 使用 GlobalAgingR 2.0.0 的 CHARLS 长数据和 `CH_filter()`。原始文件、参考脚本和包文件均记录来源与散列。
- 补回 `sleeprl`：过去一周睡眠不安频率，原编码 1–4；转换为 0–3 级的频率分数。它既不是三症状失眠负担，也不是每天睡眠小时数，更不是临床失眠诊断。
- 本阶段先固定描述性分组：<1 天、1–2 天、3–4 天、5–7 天/周；次要二分类为至少 3 天/周（原编码 ≥3）。未来每级效应需检查线性假设，不能解释为“每增加一天”。
- 睡眠时长按旧清洗方案保留 1–18 小时的观测值，仅作不同测量维度。所有暴露保留缺失；本阶段不做暴露插补、无标记前向填充或利用未来值回填。
- CESD-9 从其余九道题重算，正向题 `fhopel`、`whappyl` 反向计分；九题全部有效才给出 0–27 分。逐题计算的 CESD-10 与包总分在十题齐全者中核对。不默认包总分减一题与完整九题计分在缺失者中等价。
- W1–W2 动态模式为持续低频、发生、缓解、持续高频，要求两波均有实际观测；其关联分析只能在 W2 landmark 后开始。累计量使用两波频率分数的梯形面积（分数×年），不是每日失眠天数。此处构建不代表已拟合动态模型。

## 疾病状态与第一阶段样本

- 组件为医生诊断高血压、广义心脏病、卒中。W4 `stroke` 的 2=否，其他波次 0=否；1=是，其他/缺失保持未知。
- 第一阶段重建三值既往诊断：一旦既往报告“是”，后续保留“是”；从未阳性且本波缺失时保持未知，不能把先前“否”填入本波缺失。原始报告逆转单独计数；包内缺失是否源于问卷跳题仍需原始路由审计。
- 八种存活组合用位编码 0–7（高血压=1，心脏病=2，卒中=4）。只有三组件均确定时赋完整状态；保留组件缺失信息，不删除原始记录。缺失状态日后可考虑部分观测似然，但本阶段不决定。
- W1 基线描述样本：年龄 ≥50 岁、睡眠不安题有效、三组件均确定。选择 50 岁是本次拓展沿用 HRS/ELSA 的操作化规则，不是 CHARLS 总体入组年龄；年龄 ≥45 岁可在建模前列为敏感性。
- 基线表不要求后来仍存活或再次参加，不排除基线已患病者；它不是最终模型样本量。另列有后续确定存活状态的候选子集，不能把无后续访谈者等同未发病或死亡。
- 第一阶段不批准死亡模型。既有 `radyear` 只作候选死亡记录审计，不能因缺失死亡年份而认定存活到2020年。四条目标边均为非致死边，但是否用九状态死亡竞争模型需在下一阶段审计后冻结。
- 观察到的跨波多病跳跃保留原样，不臆造发病顺序。经验相邻确定状态计数不是连续时间模型估计事件数，也不是 q_ij；跨过缺失波次的区间要标记。

## 固定的研究问题与未来统计边界

四条目标转移：无病→仅心脏病；无病→仅卒中；仅高血压→高血压+心脏病；仅高血压→高血压+卒中。

模型拟允许单病增加，跨波多病跳跃通过兼容隐含路径积分，而不是赋造访内顺序；死亡分支暂不冻结。对四个暴露系数先报告联合检验，四条边报告全部估计和95%区间，并对四个边级检验作 BH 校正。另在两个起点分别检验心脏病与卒中系数差，使用同一模型的协方差；两项差异检验单独作 BH，报告两差异的联合检验。非显著差异不能解释为等效。

以参与者为独立单位，采用实际访谈年份、队列特定的状态结构、稀疏转移及收敛检查，不直接套用教学模型的默认 Q、时间尺度或约束。MI、诊断和模型接受标准另行固定；不为显著性改变纳排或删除转移，未继续 S0→S1 的纳排探索。

CHARLS 是测量不完全一致的外部拓展，不能直接并入 HRS/ELSA 相同失眠量表的合并效应。广义心脏病不命名为冠心病、心梗或心衰；卒中暂不拆缺血/出血亚型。
