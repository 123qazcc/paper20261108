# CHARLS 静态疾病路径：分析范围与质控

2026-09-13：不以显著性作为推进分析或改变纳排的依据。

## 四条目标路径与直接比较

静态主分析采用以下四条目标路径，以及两个起始状态内的直接比较：

1. 无高血压、心脏病或卒中 → 单纯心脏病。
2. 无上述目标疾病 → 单纯卒中。
3. 单纯高血压 → 高血压＋心脏病。
4. 单纯高血压 → 高血压＋卒中。

直接比较为上述两个起点内的心脏病系数减卒中系数，保留同模型协方差；指数化后是两个睡眠关联 HR 的比值，而不是心脏病与卒中的发生率之比。

计算仍使用已签名的9状态连续时间面板模型、20份插补、既定调整集与纳排。原代码命名中的“第二阶段”指数据准备之后的模型阶段，与本次研究路线的“第一环节”不是同一套编号。完整病例仅作预检/敏感性，不取代 MI20。
